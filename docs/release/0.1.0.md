# Rhizome 0.1.0: release notes

> Released 2026-10-08 as the first public version (tag `v0.1.0`).

## Version proposal: 0.1.0

- **Pre-1.0 on purpose.** The HTTP surface (`/v1/*`), intent kinds and journal
  event payloads are still changing task by task. Under Semantic Versioning, a
  0.x version says that any minor release may break compatibility.
- **0.1.0 instead of 0.0.x.** The system already works end to end for a local
  deployment: the board, gates, knowledge, deliverables, and JANUS-backed
  executions behind a flag. It has a CI gate and an enforced architecture
  boundary. 0.1.0 marks "first usable, first public" without promising
  stability.
- The full list of capabilities is in the `[0.1.0]` section of
  [CHANGELOG.md](../../CHANGELOG.md).

## Highlights

- **Event-sourced board.** Goals, missions, gates/questions, notes and
  knowledge, edges, deliverables and execution references all live in one
  append-only NDJSON journal. All state is rebuilt by replay.
- **Human gates as first-class data.** `question.ask` opens a decision for a
  person. `gate.approve`, `gate.reject` and `gate.requestChanges` record the
  answer, and approving requires echoing the digest of the request the person
  saw.
- **Permissions only narrow.** Policy ceilings combine by intersection and
  minimum. Every execution started from the board records the ceiling, profile
  and effective limits it ran under.
- **Enforced architecture.** `internal/archtest` fails CI if a package breaks
  the layer direction `substrate <- {execution kernel || knowledge kernel} <-
  bridge <- assembly <- surface`.
- **Zero third-party Go dependencies.**
- **Integrations by protocol, not imports.** JANUS (execution isolation and
  governance) is reached through its CLI/NDJSON contract. The Gunnflow cockpit
  UI is served through the TypeScript `gunnflow-adapter`.

## Known limitations

- **Single process, single writer.** The journal is a local file protected by
  an advisory lock. There is no replication, no multi-node setup and no
  concurrent writer. While `serve` runs, every other writer must go through
  `POST /v1/intent`.
- **Local-only binding, no authentication.** `serve` binds to `127.0.0.1` by
  default and has no built-in auth. Exposing it on a network is unsupported.
- **JANUS execution is opt-in and gated.** Real executions require an external
  JANUS (`hx`) installation, the full `-janus-*` flag set, and a deployment-owned
  `-janus-exec-config`. Without the exec config, `mission.start` is rejected.
  Real-token end-to-end runs require that external setup and are not part of CI.
- **Gunnflow contract packages (MIT).** `gunnflow-adapter/vendor/` contains
  tarballs of the Gunnflow contract packages, vendored from the Gunnflow project
  under MIT. Its license notice ships as `gunnflow-adapter/vendor/LICENSE-gunnflow`.
- **Rhizome is MIT-licensed.** See the repository-root `LICENSE` file.
- **APIs are unstable.** Expect breaking changes in 0.x minors.
